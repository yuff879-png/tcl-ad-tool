常见问题与投放规则
投放要等全部区块确认后才继续吗？
普通节点返回执行成功并核对到账金额后，等待设定间隔即可继续下一笔。最终确认、能量与 TRX 消耗由后台补查。仅广播被接受还不等于执行成功。
最小化、切换窗口或关闭窗口会怎么样？
切换窗口、遮挡或最小化可以继续投放。关闭工具窗口会暂停后续投放，保存处理中的交易后退出；也可点击退出程序。电脑休眠会中断监听。
能量不足后，重新启动会补扫、补发吗？
默认从最新已确认区块开始，不补发中断前未发送的地址。可在投放参数中分别改为续扫或补发。已广播交易先核查，首次失败后最多补试 3 次；有效期内复用原交易，确认失败或过期且未上链后才重新构建。连续 3 笔投放重试后仍未成功才暂停，成功一笔清零。能量、余额不足或到账核对异常仍立即保护暂停。
API 次数用完或节点限流怎么办？
配置的 TronGrid Key 被限流或额度耗尽时，自动切换不带 Key 的公共节点，原 Key 保留。本来没配 Key 就已在使用公共接口。公共节点也限流时等待至少 60 秒后重试，不消耗投放重试次数、不计入连续失败；运行中的任务恢复后继续，进度与哈希保留。暂停时仅继续后台核查，不会自行开始投放。自定义 RPC 可能属于其他网络，因此仅在原节点等待。
清空已投放地址，会删除统计和历史记录吗？
不会。清空的是正式或模拟的已投放地址去重名单，历史明细与统计保留。清空前自动备份，只有新的达标交易可再次命中。
换电脑后提示依赖缺失，应该怎么处理？
先确认复制了完整工具文件夹，然后运行「修复运行环境.cmd」。推荐通过「一键启动.cmd」启动，无需单独安装 Node.js。
